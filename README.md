# halo

Halo is a native macOS app (Swift 6, Xcode) that models and drives a Teenage Engineering EP-40 Riddim sampler, with a to-scale procedurally generated 3D model of the hardware and features for capturing, chopping, editing, playing, and racking samples. It's a private, single-machine project — ad-hoc signed, unnotarised, and built for one specific development environment rather than general distribution.

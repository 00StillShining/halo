## Hard technical constraints (violating any of these breaks the app)

- **Frozen entity-name contract.** The Swift app resolves parts by exact prim
  name. Every name in `/Users/stillshining/halo/Halo/Reality/EP40EntityNames.swift`
  (read it, don't edit it) must exist in the export: `ep40_root`, `chassis_base`,
  `chassis_topPlate`, `chassis_edgeBand`, `display_surface`, `speaker_grille`,
  `halo_ring`, `mic_port`, `group_a`–`group_d`, `pad_dot`, `pad_0`–`pad_9`,
  `pad_enter`, `knob_volume`, `knob_x`, `knob_y`, `fader_track`, `fader_cap`,
  `button_sound`, `button_main`, `button_tempo`, `button_sample`, `button_keys`,
  `button_timing`, `button_fx`, `button_erase`, `button_shift`, `button_minus`,
  `button_plus`, `button_record`, `button_play`, `ports_strip`, `ports_usb`.
  Underscores only (USD sanitizes dots). Extra decorative prims are fine;
  renaming or omitting contract prims is not.
- **Keep the export call exactly as-is**: `convert_orientation=True`,
  `export_global_up_selection='Y'`, `export_global_forward_selection='NEGATIVE_Z'`,
  `meters_per_unit=1.0`, `root_prim_path="/ep40_root"`, `author_blender_name=False`.
- **Units are meters, Blender Z-up.** Portrait device: X width 0.176, Y depth
  0.240 (+Y = far edge with speaker/branding), Z thickness 0.016. Controls
  protrude +Z.
- **No text/glyph geometry smaller than 2.1 mm.** Smaller text tessellates into
  near-degenerate triangles and RealityKit then renders the ENTIRE scene blank —
  silently, no error. This was diagnosed by bisect; don't rediscover it.
- **Keep `bpy.context.scene.world = None`** before export (no baked DomeLight —
  the app owns lighting).
- The script must keep running headless (`--background --python ... -- <out>`),
  deterministic, no external assets, no pip dependencies.
